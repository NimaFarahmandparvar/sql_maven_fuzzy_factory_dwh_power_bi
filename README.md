## **About Project**
### The purpose of this project is to build a data warehouse with SQL Server which includes ELT processes and data modeling. In addition, Exploratory Data Analysis (EDA) and interactive reports are developed by using Power BI. The assumption is that the dataset gets updated frequently.

## **Dataset Source**
### Toy store e-commerce dataset is downloaded from [MavenAnalytics](https://mavenanalytics.io/data-playground/toy-store-e-commerce-database).
